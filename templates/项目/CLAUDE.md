# 课题科研原则（长期生效，保持简短；详细方法见 skills）

## 授权方式：研究目标授权制
- 目标、参照、成功标准、预算、边界都在 `goal.yaml`，**只读**。
- 在授权范围内自主做：提出假设、设计网络、写代码、跑 Toy/Pilot 实验、记录结论。
- **尽量别停**。需要用户决定的事（晋级 Full、判据修正、待删文件、产品选项）写进 `pending_approvals`，继续做别的。
- 只有三类事停机（status 改为 `needs_approval`）：改变研究目标/转向、超预算、不可逆的对外操作（公开仓库、许可证）。

## 自主循环
按 `autoresearch-loop` skill 执行：提出假设 → 预注册 → Toy（≤5 分钟）→ 证据评估 → 晋级或修正 → 记录。

## 可靠性底线
- 先预注册（protocol.md 提交到 git）再跑实验，判定标准不得事后改。
- 结论被判存疑/否定后，不得在同一测试集上换检验救回来；复验必须用新划分或新数据。
- 与最强合理基线比较（基线与新方法同等调参预算）；提升须配对 bootstrap 95% 置信区间不跨 0，且 ≥3 个真有随机性的种子方向一致，才算"有效"。
- 早停选点用验证集，报告用另一测试集。
- 不改 `eval/`、测试集划分、基线结果；遇到错误不换方法/模型/数据集绕过。
- 负面结果如实写进 `findings.md`；不编造结果、引用和理论解释。

- 实验只通过 `python 实验.py` 运行；守卫 hook 拦截的操作不得换写法绕过。
- 算力由 实验.py 自动选（本机 4090 / ku-h100 H100 / madar H200，谁先跑完用谁）；长实验加 `--预计分钟 N` 让它估得准。选中集群时命令立即返回，结果之后自动同步回 hypotheses/。

## 研究取向
- 改进由已观察到的问题引出；找现有方法解决不了的缺口，有人做过不要紧。
- 同等效果下选更简单、更符合直觉的方案；快但不能糙。
- 不成立就干脆放弃，不拖。
- 先用 ≤5 分钟的实验验证，不写长篇分析。

## 无人值守运行
- 这是无人值守运行，没有人会替你执行命令。某条命令被拒时，拆成更简单的单条命令重试（不用花括号展开 `{a,b}`、循环、变量赋值、过长的组合命令），而不是停下来让人手动运行。
- 被拒的提示可能写"Bash 权限被拒"，这只针对那一条命令，不代表 Bash 整体不可用。
- research-state.yaml 只用块格式（每个字段一行，长文本用 `>-`），不用 `{...}` 行内映射；写完用 `python -c 'import yaml;yaml.safe_load(open("research-state.yaml"))'` 验证。
- 测试集已封存：测试指标只能用 eval 的 score()/correct_mask()，并写明假设编号，且需要人批准（approvals/测试集_H编号.ok）；训练脚本里不要算测试准确率；选参和挑基线只用验证集。
- 运行 Python 直接写 `python`（课题环境已在 PATH 最前），不要写 conda 环境的绝对路径，否则会被拒。
- 下面几种写法在本模式下必被拒，一开始就别用（11-22 巡检：每轮都浪费一次）：命令前加环境变量（`CUDA_VISIBLE_DEVICES=1 python …`，GPU 已由 实验.py 按 goal.yaml 设置）、用 `&&` / `;` / `|` 串多条命令、`cd 子目录 && …`、`sed -i` 改文件（改文件用 Edit）。每次只发一条命令。课题根目录的 `实验.py`、`汇报PPT.py` 是指向 harness 的软链接（Glob 搜不到，但存在），直接 `python 实验.py …`、`python 汇报PPT.py …` 调用。读文件、搜内容一律用 Read / Grep / Glob 工具，不用 `cat`、`grep … |` 之类的 shell 命令。
- 写或追加文件一律用 Edit/Write 工具；shell 重定向（`>`、`>>`、`cat >> 文件 <<EOF`）在本模式下总是被拒。程序输出要存文件，就让程序自己写（如 `--out 路径`）。
- 如果 `logs/最新审查.md` 存在，先读：其中与你本轮任务相关的高/中问题优先处理，处理了哪几条写进提交信息。

## 状态与记忆
- 研究事实只存在文件里：`research-state.yaml`、`findings.md`、`hypotheses/H*/`、git 历史。不依赖聊天记录。
- 每次迭代结束：更新 state、追加 findings、git commit（信息用中文写清做了什么、结论）。

## 质量
- 代码：简洁、最小改动、中文注释、固定随机种子、结果存 JSON。
- 图：英文、素风格、可复现脚本生成。
- 文件夹/文件名用清楚的中文含义。
