# 我的科研写作与绘图标准

这个 skill 不重复造轮子：具体做法交给 4 个现有 skill，这里只做两件事：**分派**，以及**用用户偏好覆盖冲突规则**。
完整偏好见 `references/偏好检查表.md`（45 条，编号 A1–E10），交付前逐条自查。

## 1. 分派
| 任务 | 用哪个 | 何时 |
|---|---|---|
| 写或改段落 | `sentence-mimic` | 先拿同类顶刊范文抽句型模板，再写（A1、B13） |
| 画统计图（定稿级） | `figmirror` | 有一张顶刊范图可照着画时；成本高，草图不用 |
| 设计或审查方法图、Fig.1、结果图 | `figure-designer` | 审图、定版式时（C15） |
| 交给老师前检查图、表、PPT | `glance-check` | 每份交付前一次（A8、E1） |
| 投稿前全面审查 | `pre-submission-reviewer` | 投稿前一周一次 |
| 中译英、去 AI 腔 | 本 skill 直接做，按 B7 逐句改，交付"原句 → 新句"（A6） | 需要时 |
| 表格、PPT 版式 | 本 skill 第 3、4 节 | 现有 skill 没有覆盖 |

## 2. 覆盖规则（现有 skill 与用户偏好冲突时，以这里为准）
| 来源 | 它的规则 | 改为 |
|---|---|---|
| figure-designer、pre-submission-reviewer | 图注首句写结论、图注要详细 | 图注简短，只描述不下结论（C9） |
| figure-designer | 图内字体随正文用衬线 | 一律英文，Nimbus Sans（C2） |
| figure-designer | Ours 用强对比色、粗体 | 彩色只给数据；粗体只标真正最佳值（C5） |
| glance-check | 结论那条线上色、其余变灰 | 可以，但只对数据线上色，文字仍全黑（C5） |
| glance-check | 术语注释挪进讲稿或改成表下小字 | 术语解释留在页旁（术语加粗一行 + 白话一行）；页面不放小字（11-22） |
| glance-check | 拼图页标题写统计性结论 | 拼图只当例子，标题写描述；统计结论要全量统计支撑（11-22） |
| glance-check | 收尾页标题改成一句结论、统一白底 | 保留 Take-aways 收尾页（KU 模板），3 条要点即结论（11-22） |
| pre-submission-reviewer | 要求写出 limitations | 论文不加局限句、不放不利数字（B1）；相关工作写前人不足（B3）；但不编造、不说满（B2） |
| pre-submission-reviewer | 禁用 yet、reveal 等词 | 只作提示，按 B7①"领域常用词"判断 |
| sentence-mimic、figmirror | 照范文、范图模仿 | 模仿结构和做法，保持用户文风（B7⑤）、字体与颜色口径（C2、C5） |

## 3. 表格（现有 skill 未覆盖）
- 表头、行名不用带点的缩写（Val. Acc.、diff.、aug.）：写完整词，放不下就删词，不加点缩写（D6a）。
1. 先说这张表的用途和唯一结论（D4），审稿人视角打分（A2），找同类顶刊表对照（A1）。
2. booktabs，无竖线；指标列名加 ↑↓；行名列名短而清楚，列标题行数统一（D6）。
3. 粗体只给真正最佳值（C5）；不是每个数都标，第一眼能找到重点格（D2）。
4. 标题一句话，说明放表注；表注简短，正文已分析的不重复（C9）。
5. 每个数字可追溯到结果文件（B11）；对比他人结果的格子注明出处，查不到写"未知"（D7）。

## 4. PPT（现有 skill 未覆盖）
0. **一律用固定版式工具**，不要自己用 python-pptx 摆版面：写一份内容 JSON（格式见 `汇报PPT.py` 文件开头），运行 `python 汇报PPT.py 内容.json 输出.pptx --严格 --预览`，把 `[检查]` 报出的问题全部改完，**再用 Read 打开 `[预览]` 给出的总览 PNG 逐页看**（折行、字小、留白、重叠这些文字检查发现不了），看过才算完成。内容页必填 `引导`（标题下的引导问题，承接上一页）；有不常见术语时填 `术语`（页旁白话解释）；标题写陈述句，不写问句。工具基于 KU 模板：白底蓝字封面、Title Only 内容页、灰底章节页、黑底 Take-aways 收尾，不加 Thank You 页；不做单独的大数字页；页面上不放出处和页底灰色小字，出处只写进讲稿备注。**配色死规定：只用黑、蓝、红**（灰为黑的深浅），不用绿、黄、橙。
1. 先给汇报思路和每页规划（E4），故事不够就不凑（E3）。每页规划写明：一句话结论、主图或主表、分钟数。
   - **时长按慢语速算**：各页分钟数之和 × 1.3 ≤ 规定时长（15 分钟报告约 11.5 分钟内容）；超了就删页，不靠讲快。
   - **大标题能在本页找到答案**：写成本页图表能直接证明的陈述句，不用问句。
   - **每页内部连贯**：左右、上下的元素必须互相说明，无关内容挪进讲稿；不放提示框或总结框，结论写进标题。
   - **每页由动机引导、直观好懂**：每页先让人知道"为什么要看这一页"（上一页留下的问题 / 这一页要解决的疑问），再给图表回答；页与页之间是一条问题链，不跳跃，不堆事实。
   - **术语用社区常用说法并在页旁白话解释**；页面上不放引用式旁白句（口头带过，写进讲稿）。
   - **每页扫一眼就懂**：一个图或表 + 结论式标题，正文只留关键词和例子；讲稿第一行"这页只说一句：……"。
   - **论文分享报告**：分"讲论文"和"结合自己项目"两部分，分隔页隔开；第一部分以小结页（做到了 / 作者承认没做到）收尾，第二部分先用一页介绍项目。讲论文以原文为准，不只看笔记。
2. Jia-Bin Huang 版式：每页 ≤3 行、标题写结论、无自我介绍和大纲页、停在总结页（E7）。
3. 逐页问"需要这页吗"，不放 backup（E2）；多图多直觉，表多就拆页或直观化（E6）。
4. 按观众理解顺序；讲表时写出说话顺序（E5）。
5. 给老师用英文版、可编辑 .pptx（E8）；配 1–2 页 PDF 要点（E10）；交付前跑 glance-check。

## 5. 交付前自查
**两个硬性步骤，没做不算完成**（11-22 巡检：多次自述"未做 sentence-mimic / glance-check"后照样交付）：
1. **写或改段落** → 调用 `sentence-mimic`。无人值守时不问人，默认：对象 = `逐句拆解.md` 里同体裁的段落（结果段学结果段），目标 = 本段。交付物里必须附"逐句职责表"（范文每句干什么 → 我们对应的句子），没有这张表就是没做。
2. **PPT、图、表交付** → 调用 `glance-check` 一次，按第 2 节覆盖表处理冲突；交代里列出它的发现和每条怎么处理（改了 / 按覆盖表不改）。
- **不跨假设合并计数**：不同假设、不同协议的种子或结果不能合在一起数（如"25 对里 24 对占优"），尤其不能把"存疑后加种子重判"的那组算进去；每个结论只引用它自己那次预注册的判定（11-22 巡检，审查标为高）。
- **全稿数字口径一致**：同一个结果在各页写法要一致（"35.4 个百分点"不要别处写"约 35"）；不同配置的准确率要写明是哪个配置（11-22 巡检，glance-check 发现）。
- **样本拼图只当例子**：拼图（几张样本、单个种子）不能撑起统计性标题（如"错误多是相似类混淆"）；要下这种结论需要混淆矩阵等全量统计，否则标题写成描述（"随机抽 8 个错例"），按单种子观察只算线索处理（11-22 巡检发现）。
- **审查意见要落到每一处引用**：`logs/最新审查.md` 质疑过的数字或措辞（如"同等调参"、偏窄的 CI），PPT、论文里每一处用到它的地方都要改成审查后的说法，不能只另加一页"审查问题"而原页照旧（11-22 巡检发现）。
- 对照 `references/偏好检查表.md` 中与本任务相关的类别逐条过；不满足的改掉，或说明为什么不适用。
- 说清参照了哪个范例（A1）、改了什么（A6：原句 → 新句、文件路径）。
- 适用范围：在对话中按 A3/A4/E4 小步推进等确认；在 harness 自主运行中不停下，把意图、参照、改动写进记录，留到简报或交接审。

## 6. 记录新偏好
用户提出新的风格或质量要求（"以后……""不要……""一律……"）时：
1. 用一句话复述规则并请用户确认。
2. 确认后追加到 `references/偏好检查表.md` 的"新增"一节：日期 · 类别 · 规则 · 原话。
3. 若与已有条目冲突，指出冲突的编号，问用户以哪条为准，再改旧条目。
