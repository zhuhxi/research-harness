# 逐句学习与仿写

用户要的工作方式：**逐句学习 → 抽取精华 → 仿照改写**。不要只给高层建议，要落到句子。

语料和已有成果在 `<你的笔记目录>/反问题顶会调研/扩散流反问题/包装学习/`：
- `套路手册.md` —— 从 86 篇论文提取的量化套路（标题词数、摘要句式、新意措辞频次等）
- `逐句拆解.md` —— 摘要、引言、图注、结果段的逐句职责表 + 句式工具箱
- `逐句学习_结果段.md` —— 一次完整的"拆解 → 抽核 → 仿写"记录，可当范本
- `Naseer个人分析/pdf/` —— 86 篇 arXiv 原文

参数是要学的对象和要改的目标，例如"用他的结果段写法改我们 §6"。没给时：对话中就问；无人值守（harness / 巡检）时不问，默认对象 = `逐句拆解.md` 里同体裁的段落，目标 = 当前要写的段落（11-22）。

## 五步

1. **选同类段落**。结果段学结果段，引言学引言，图注学图注。跨体裁套会走形。
   用 `pdftotext -f N -l M <pdf> -` 取原文。

2. **逐句列表**。一句一行：这句干什么。**先如实标注，不评价好坏**。
   典型职责：共识 / 机制铺垫 / 转折 / 规模 / 定义自变量 / 指向图表 + 给结论 /
   解释协议不对称 / 配平对比 / 极端例子 / 泛化声明 / 指向附录 / 过渡。

3. **抽内核**。把每句的职责抽成**去掉领域词**的模板。
   例：`[图表号] 中的结果表明 [结论]。` / `For example，[配平的对照] 得到 [数字] 而 [我们的] 得到 [数字]。`

4. **诊断我们的段落**。对着模板逐条打勾打叉。常见缺失：
   - 指了图表但没在同一句给结论（空句）
   - 对比没配平，或配平依据没写进括号
   - 协议不对称没解释
   - 没有把旋钮推到头的极端例子
   - 结尾没把结果拉回主论点

5. **改写，并算页数代价**。加进来的每一行都要从别处的**重复表述**里抠回来。
   顶会论文有硬页数上限，改写不能让论文变胖。改完必须重编译并核对页数。

## 顺序：先图表，后文字

用户的工作原则：**该加图就加图，不要被页数卡住；图表定下来之后再压文字。**
加图时先不管超页，因为图一旦到位，正文里大段"复述图"的文字就成了可删的冗余——
那些冗余往往正好抵掉图的版面。反过来先压文字再加图，会把该留的内容删掉。

所以第 5 步的顺序是：
1. 先把图做出来、插进去、编译，**允许暂时超页**；
2. 再扫一遍正文，找出现在只是在复述图的句子，删掉；
3. 最后才做词级微调。

## 纪律

- **引用原文最多几个词**，其余一律转述。学的是句子的职责分工，不是辞藻。
- **抄结构不抄内容**。模板是公共的写作技艺，具体论断必须是我们自己的数据。
- **不要为了套模板而编数据**。模板要求"极端例子"而我们没有，就不写。
- 每次改写后**重新编译、核对页数、核对没有新的 overfull 和 undefined reference**。
- 改动记进对应的 `包装学习/` 文档，写清**留下了什么、删了什么、为什么**。

## 汇报

说人话，中文。先给结论，再给表，最后给建议。
要说清楚：改了哪几句、为什么这么改、页数代价多少、哪些模板**评估后没用**以及原因。
